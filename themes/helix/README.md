# Bundled Helix themes

These theme files are copied unchanged from the
[Helix editor](https://github.com/helix-editor/helix) (`runtime/themes`,
commit 57d8641). They are licensed under the Mozilla Public License 2.0
(see `LICENSE` in this folder), with each file's authors named at the
top of the file. Treelights converts them to its own theme data at build
time with `tools/gen-helix.ts`.
